# 🎨 ComicCraft AI - AI-Powered Comic Generator

> Transform your stories into stunning comics using Gemini AI!

## ✨ Features
- 📝 Story to Comic - Converts text to comic script using Gemini Pro
- 🖼️ AI Image Generation - Auto generates panels with Gemini Flash
- 📚 Smart Layout Builder
- 📦 Export as PDF / Images

## 🛠️ Tech Stack
Python, FastAPI, Google Gemini, HTML/CSS, Jinja2, Pytest

## ⚙️ How to Run
pip install -r requirements.txt
python main.py
Open http://localhost:8000
